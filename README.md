# Dunkelmodus Anpassungen

## Übersicht
Dunkelmodus Anpassungen ist ein Tool, das Entwicklern und Designern ermöglicht, stilvolle und benutzerdefinierte Dunkelmodus-Designs für ihre Websites und Anwendungen zu erstellen. Es soll ein einfaches Interface bieten, um Farben, Hintergründe und Schriftarten zu ändern und zu testen.

## Funktionen
- Intuitive Benutzeroberfläche zum Anpassen von Farben und Stilen.
- Echtzeit-Vorschau der Änderungen.
- Möglichkeit, Designs zu speichern und später wiederzuverwenden.
- Export-Funktion zum Download von CSS-Stilen.
- Unterstützung für die Integration in gängige Frontend-Frameworks.

## Installation
1. Klone dieses Repository.
2. Führe `npm install` aus, um die erforderlichen Abhängigkeiten zu installieren.
3. Starte die Anwendung mit `npm start`.
